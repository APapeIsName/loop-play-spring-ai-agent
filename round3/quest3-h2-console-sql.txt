## 5. 운영 시 추가 SQL 예 (참고)

```sql
-- 90일 이전 세션 자동 삭제 (Round 5 TTL 정책)
DELETE FROM SPRING_AI_CHAT_MEMORY WHERE "timestamp" < NOW() - INTERVAL '90' DAY;

-- 활성 세션 수
SELECT COUNT(DISTINCT conversation_id) AS active_sessions FROM SPRING_AI_CHAT_MEMORY;

-- 세션별 메시지 수 분포
SELECT conversation_id, COUNT(*) AS msg_count FROM SPRING_AI_CHAT_MEMORY
GROUP BY conversation_id ORDER BY msg_count DESC LIMIT 10;
```
